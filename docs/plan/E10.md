#### T101. Задачи модулей в сборке страницы образцов

- **Цель:** сборка страницы образцов несёт задачи модулей из релиза `modules`, которые даёт `module-kit open`, а образец задачи модуля несёт ссылку на неё, которую CI `modules` сверяет с пакетом коммита. Так закрывается Д4, вторая из двух причин, по которым назначение «eval-набор» закрыто. Первая — набор `eval-set` в `legal-1` релиза `spec` пока черновик — ждёт `spec`, и откроет назначение переход на тег `spec`, где `eval-set` в силе (architecture 3.6; R69).
- **Почему:** просьба `modules` к его задаче T62 эпика E8 — первым образцам автора в eval-наборах модулей; я передал её 2026-11-11, после T91. Это пункт 4 прежней просьбы `modules`, который T89 оставила в «Открыто». Образцам автора нужнее всего то, чего генератор синтетики не рисует: экземпляры шаблонов по зерну, выбор, написанный от руки, и сочинения (T86, T97).
- **Просьба `modules`, по пунктам:**
  - задачи модулей в сборке страницы (Д4) — из релиза `modules` через `module-kit open`: оба индекса проверены `release-verify`, а пакеты — по их записям;
  - что страница пишет в образец задачи модуля. `just eval-match` в `modules` сверяет `task.open_view_digest` образца человека с `module-kit open` над пакетом коммита, а у шаблона — экземпляр по `task.seed` (поправка T59 к R25 modules). Нужны источник `modules` с ID модуля, `task.task`, у шаблона `task.seed`, и дайджест открытого вида той же проекцией, что даёт `module-kit open`;
  - тег релиза `canvas`, где назначение «eval-набор» откроется, — когда сойдутся оба условия;
  - подтверждение, что случайный ID образца человека никогда не начинается с `synthetic-`, и вид этого ID. Сессия Claude Code в `modules` не читает файлов `eval/` модулей, кроме `synthetic-*.json` (поправка T61 к R04 modules);
  - имя сохранённого файла: если страница называет файл `<id>.json`, автору не придётся его переименовывать — в `eval/` модуля файл лежит как `eval/<id>.json`;
  - заявление автора для eval-набора не нужно: автор подписывает форму добровольца и принимает её сам (поправка T61 к R04 modules). Второе заявление страницы, «форма … подписана и принята организатором», ему подходит.
