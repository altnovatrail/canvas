# TASKS.md — tasks outside an epic of `canvas`

Open tasks outside the current epic, each as its body, in Russian (R154 spec, R155 spec).

- Never read whole: a session reads only its own task — `grep -n '^#### T' run/TASKS.md` lists them, `awk '/^#### T114\./{p=1;print;next} /^#### /{p=0} p' run/TASKS.md` gives one body.
- A new task outside an epic goes here as a body, its number the one free when it is written down (RUN.md, Citations). When done, the body leaves for the archive (RUN.md rule 9).

- **Цель:** в разделах `##` журнала `docs/decisions.md` от «`spec` tag v0.12.0 and format 0.4» до «Modules' tasks on the samples page» включительно ссылка стоит, только если читатель пойдёт по ней, чтобы действовать (R171 spec), и нет датированных поправок: каждая свёрнута в действующий текст своей записи.

Часть задачи T138, разбитой по правилу 11 RUN.md и шагу 9 её текста: T138 — план, CLAUDE.md, `.claude/rules/` и комментарии кода; журнал решений — T139–T146 по своим разделам `##`; `docs/architecture.md` — T147; `docs/sources.md`, `docs/measurements.md` и ключ — T148. Объём — около 14 тыс. слов, 26 поправок.
- **Зависит от:** T144.
- **Сделать:**
  1. Каждую датированную поправку раздела — абзац «— *…Amendment <дата>…*» и ссылку вида «the 2026-10-21 amendment to R25 spec» — свернуть в действующий текст записи, на месте: «Почему», отвергнутое и цитаты источников сохранить (R160 spec). Хвост «— *Consequence:*» — список файлов и разделов, которые правит изменение решения, без номеров задач. Ссылку на поправку записи `spec` — заменить ссылкой на запись.
  2. Каждая ссылка раздела — по правилу: внешний факт, который можно оспорить, — одна запись `sources`/`measurements`; решённый выбор, который выглядит изменяемым, — один номер решения, один раз в тексте; строки «Д…» и «В…» — можно; номер задачи — заменить файлом, решением или словами; остальное — убрать; в скобке не больше двух ссылок; цепочку — свести к одному месту, где утверждение решено.
  3. Смысл не менять: правка — только ссылок и того, что их окружает, и свёртка поправок. Запись, которая при свёртке оказалась противоречивой, или ссылка, о которой есть настоящее сомнение, — строка таблицы 3 (`run/QUESTIONS.md`), не правка наугад.
  4. Остальные разделы журнала не трогать: их берут свои части. Ключ `"citations": true` не включать — его включает T148.
  5. В описании PR — таблица «поправка → место в новом тексте», для ревью.
- **Как проверить:** `just -f spec/justfile docs-check-repo` — зелёный; тот же запуск с временно включённым ключом `"citations": true` в `docs-budgets.json` не называет ни одного места в разделах этой части (ключ вернуть); `/code-review high`, один круг.
- **Разделы:** R171 spec, R160 spec; RULES.md spec — The bar и Citations; `spec/repo-template/files/docs/decisions.md`; свой `docs/decisions.md`, разделы этой части.
